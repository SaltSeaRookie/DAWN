# 晨曦大陸 Dawnlands

一款原創的網頁版 2.5D（等角視角）動作 RPG。所有美術都以 Canvas 程序化繪製，沒有外部圖檔，也不需要建置工具。

## 遊玩

直接用瀏覽器開啟 `index.html`，或啟動一個本機伺服器：

```bash
python3 -m http.server 8000
```

然後打開 http://localhost:8000 。

## 操作

| 操作 | 說明 |
| --- | --- |
| 點擊地面（可按住） | 移動 |
| 點擊怪物 | 自動接近並攻擊 |
| 點擊地上物品名稱 | 撿取 |
| 點擊 NPC | 商店、傳送、委託 |
| 1–9 | 快捷列：藥水、治癒術、神聖武器、防護罩、回村卷軸、自動狩獵 |
| I / C / M | 背包 / 角色 / 小地圖 |
| Tab | 攻擊最近的怪物 |
| Enter | 聊天 |

## 內容

- 兩種職業：劍士（近戰）與遊俠（弓箭）
- 五個區域：晨風村（安全區域）、碧波草原、幽影森林、骸骨荒原、赤岩峽谷（深處有頭目「赤鱗飛龍」）
- 7 種怪物、掉落物、金幣、商店買賣
- 武器 / 防具強化卷軸（超過安全值可能失敗而消失）
- 委託任務鏈、等級成長、正義值、日夜循環與光源
- 每 30 秒自動存檔到瀏覽器 localStorage

## 檔案結構

```
index.html
css/style.css
js/util.js     亂數、噪聲、A* 尋路
js/data.js     物品、怪物、職業、委託資料
js/world.js    地圖生成、地表貼圖、建築與物件
js/sprites.js  角色、怪物、圖示繪製
js/render.js   等角渲染、深度排序、夜晚光照、小地圖
js/ui.js       HUD、視窗、商店、對話
js/game.js     遊戲邏輯、戰鬥、AI、主迴圈
```
