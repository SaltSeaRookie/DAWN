# 晨曦大陸 Dawnlands

一款原創的網頁版 2.5D（等角視角）中世紀奇幻 RPG。所有美術都以 Canvas 程序化繪製，沒有外部圖檔，不需要建置工具。

## 遊玩

```bash
python3 -m http.server 8000
```

打開 http://localhost:8000 。也可以直接用瀏覽器開啟 `index.html`。

## 流程

1. **登入畫面**：輸入帳號密碼。帳號不存在時可直接建立（本機模式，資料存在瀏覽器）。
2. **選擇角色**：每個帳號最多 4 個角色，可建立、刪除、查看能力值。
3. **建立角色**：四種職業，力量／敏捷／體質／智力／精神／魅力六項能力值，另有 6 點自由分配。

## 職業

| 職業 | 定位 | 特色 |
| --- | --- | --- |
| 騎士 | 近戰 | 體力與防禦最高，重擊、雙手巨劍 |
| 法師 | 魔法 | 光之箭、冰錐、雷擊、火球、流星火雨 |
| 遊俠 | 弓手 | 遠程射擊（消耗箭）、疾風箭、大地之膚 |
| 牧師 | 輔助 | 各級治癒術、神聖武器、驅散亡靈、神聖光環 |

## 系統

- **地圖**：原創大陸（晨風村、林語村、銀風港、鐵砧鎮、灰岩城、河流與橋、海岸、草原、森林、荒原、峽谷、沙漠、高地）＋地下城「地下墓穴」。按 M 開啟羊皮紙世界地圖。
- **怪物**：17 種怪物，含赤鱗飛龍與墓穴領主兩隻頭目，各有掉落表。
- **道具**：11 個裝備欄（頭盔、項鍊、盔甲、斗篷、武器、盾牌、手套、腰帶、長靴、兩個戒指）、職業與等級限制、雙手武器、飾品屬性、屬性抗性。
- **負重**：超過 50% 不會自然回復，80% 移動變慢，滿載無法撿取。各村莊有共通倉庫。
- **魔法**：5 個階級共 18 種魔法，向魔法商人購買魔法書學習，高階書只能打怪取得。魔法視窗顯示魔攻與魔防。
- **強化**：一般／祝福強化卷軸，超過安全值可能失敗並讓裝備消失。
- **PK 與善惡值**：野外有其他冒險者與紅名的邪惡冒險者。Ctrl／Shift＋點擊可強制攻擊（變紫名），殺害無辜者會變成邪惡，村莊守衛會攻擊你，死亡時會掉落物品。
- **血盟**：等級 5 支付 3000 金幣建立，自訂名稱與徽章；在村莊邀請冒險者加入（魅力影響人數與成功率）；可召集盟友助陣。
- **攻城**：在灰岩城外向攻城傳令官宣戰，10 分鐘內攻破城門、摧毀守護之塔即可成為城主，收取稅金，並防守敵對血盟的突襲。
- **畫面**：低解析度像素風與昏暗中世紀色調（可在設定中關閉）、日夜循環、地下城的火把光照。
- **音訊**：登入畫面為程式譜寫的原創曲；遊戲中播放 `assets/music/theme.mid`；音效全部程序化生成；音樂與音效可分別開關。

## 操作

| 按鍵 | 功能 |
| --- | --- |
| 點擊地面／怪物／物品／NPC | 移動／攻擊／撿取／對話 |
| Ctrl 或 Shift＋點擊 | 強制攻擊 |
| 1–9、0 | 快捷列（可從背包或魔法視窗拖曳圖示設定，右鍵清除） |
| I／C／S／P | 背包／角色／魔法／血盟 |
| M／N／O | 世界地圖／小地圖／設定 |
| Tab／Enter／Esc | 最近的怪物／聊天／關閉視窗 |

## 多人連線的擴充空間

`js/net.js` 把帳號、角色存檔與玩家指令（移動、攻擊、施法、撿取、對話）都包在 `Net` 介面後面。目前使用 `LocalBackend`（瀏覽器 localStorage），將來只要實作一個介面相同的遠端後端（例如 WebSocket），把 `Net.backend` 換掉，並讓伺服器處理 `Net.intent(...)` 送出的指令即可。所有實體都有唯一 id，便於同步。

## 檔案結構

```
index.html, css/style.css
assets/music/   遊戲背景音樂 MIDI（theme.js 為 base64 版本，讓 file:// 也能載入）
js/util.js      亂數、噪聲、A* 尋路
js/data.js      職業、能力值、道具、魔法、怪物、商店、委託
js/net.js       帳號／角色存檔／玩家指令的網路層（目前為本機）
js/world.js     大陸與地下城地圖生成
js/assets.js    地表貼圖與靜態物件繪製
js/sprites.js   角色、怪物、城門、圖示、血盟徽章繪製
js/audio.js     MIDI 解析與合成、原創登入曲、程序化音效
js/render.js    等角渲染、像素模式、光照、小地圖、世界地圖
js/ui.js        HUD 與所有視窗
js/scenes.js    登入、選擇角色、建立角色
js/game.js      遊戲邏輯：戰鬥、AI、魔法、負重、PK、血盟、攻城
```
