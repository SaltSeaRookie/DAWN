# 晨曦大陸 Dawnlands

一款原創的網頁版 2.5D（等角視角）中世紀奇幻 RPG。所有美術都以 Canvas 程序化繪製，沒有外部圖檔，不需要建置工具。

## 遊玩

```bash
python3 -m http.server 8000
```

打開 http://localhost:8000 。也可以直接用瀏覽器開啟 `index.html`。

## 流程

1. **登入畫面**：輸入帳號密碼。帳號不存在時可直接建立（本機模式，資料存在瀏覽器）。
2. **選擇角色**：每個帳號最多 4 個角色，可建立、刪除、查看能力值。
3. **建立角色**：四種職業，力量／敏捷／體質／智力／精神／魅力六項能力值，另有 6 點自由分配。

## 職業

| 職業 | 定位 | 特色 |
| --- | --- | --- |
| 騎士 | 近戰 | 體力與防禦最高，重擊、雙手巨劍 |
| 法師 | 魔法 | 光之箭、冰錐、雷擊、火球、流星火雨 |
| 遊俠 | 弓手 | 遠程射擊（消耗箭）、疾風箭、大地之膚 |
| 牧師 | 輔助 | 各級治癒術、神聖武器、驅散亡靈、神聖光環 |

## 系統

- **主線故事「失落的月之碑」**：從晨風村的流浪學者艾德溫開始，共 6 章——收集月之碑碎片、拜訪林語村長老菲恩、解放幽影森林深處被黑影纏住的影縛樹精、取得月之鑰打開月影之門、喚醒月影遺跡的三座月之碑，最後在月之祭壇擊敗蝕月之主。每一步都有劇情對話與獎勵，完成後獲得稱號「月光守護者」與月光項鍊。畫面左上角會顯示目前的章節與目標（點擊可開啟冒險日誌），小地圖與世界地圖上的 ★ 是目標的位置，有劇情要說的 NPC 頭上會出現「!」。
- **月影遺跡**：取得月之鑰後從幽影森林深處的月影之門進入（之後傳送師與月影遺跡傳送卷軸也能前往）。被紫色月光籠罩的古代精靈遺跡，有月鏡湖、古王迴廊、月光水晶與三座月之碑。怪物有月紋蜘蛛、月影幽魂、墮落精靈射手、遺跡守衛、蝕月騎士；頭目**蝕月之主**會連射暗影彈、近身時施放蝕月新星、召喚月影幽魂、體力低時瞬移到你身後，完成主線後會定期在祭壇重生，掉落蝕月系列裝備與高階魔法書。

- **地圖**：原創大陸（400×400 格；晨風村、林語村、銀風港、鐵砧鎮、沙漠的綠洲鎮、高地的霜嶺村、灰岩城、河流與橋、海岸、草原、森林、荒原、峽谷、沙漠、高地）＋地下城「地下墓穴」＋海外的「翡翠群島」（在銀風港找船長搭船，有珊瑚鎮、叢林、海盜灣與深海巨蛇）＋「熾焰火山」（赤岩峽谷東北的火山隘口、傳送師 600 金幣或火山傳送卷軸）。＋北境「歐瑞城」（霜嶺高地北方的北境山道、傳送師 1000 金幣或歐瑞城傳送卷軸）。按 M 開啟羊皮紙世界地圖，可切換大陸、群島、火山與北境。
- **村莊佈置**：每個村莊有自己的街道、房屋樣式、道具與專屬語彙，走進不同區域會顯示地點名稱（例如「銀風港・第一碼頭」）。銀風港有兩座碼頭、燈塔、小船、魚貨攤與曬網場；鐵砧鎮有熔爐、鐵砧與礦車；綠洲鎮有泉水、帳篷與駱駝市集；霜嶺村有積雪木屋、柴堆與獵人小屋；林語村有紙燈籠與森之祠。村民與商人的台詞、商人的職稱也依村莊不同。
- **北境・歐瑞城**：石牆圍起的雪國城市，有雜貨、武器防具（賣霜刃、冰河長弓、寒霜法杖、寒鐵鎧甲等北境裝備）、魔法、飾品、倉庫、寵物、傳送師與血盟管理員。城外有北境雪原、霜松林、冰封湖與冰河峽谷，怪物有雪原狼、霜魂、雪怪、冰晶巨像、霜巨魔，最深處的頭目**霜冠巨人王**會震地、降下冰錐風暴、召喚雪怪，並在體力低時狂暴。北境也有冒險者在練功。
- **熾焰火山**：熔岩河、黑曜石橋與炎皇巢穴。站在岩漿旁每 2 秒受到熱氣傷害，火屬性抗性 60% 以上可完全抵擋（抗火藥水 +30%、火系裝備）。怪物有熔岩史萊姆、地獄犬、火焰蜥蜴人、炎魔、熔岩巨像、龍人戰士，最深處是頭目**炎皇火龍**：扇形龍息並留下燃燒地面、體力 60% 以下降下流星火雨、70%／35% 時召喚幼火龍、35% 以下狂暴。
- **怪物**：37 種怪物，含赤鱗飛龍、墓穴領主、海盜船長、深海巨蛇、鋼鐵巨像、炎皇火龍等頭目，各有掉落表。
- **道具**：共 193 種道具，含回魔裝備、火龍系列（炎皇之劍、龍息長弓、熔岩法杖、龍鱗鎧甲、龍翼斗篷、龍心項鍊…）與新消耗品（抗火藥水、龍血藥劑、經驗卷軸 +50%、火山傳送卷軸）、11 個裝備欄（頭盔、項鍊、盔甲、斗篷、武器、盾牌、手套、腰帶、長靴、兩個戒指）、職業與等級限制、雙手武器、飾品屬性、屬性抗性。
- **交易**：點擊其他線上玩家選擇「交易」，雙方把物品與金幣放上交易欄，都按「確認交易」才會成交（任何一方修改都要重新確認）。也可以和電腦冒險者交易：點擊冒險者選「交易」，挑選對方的物品或向對方要求金幣，對方會評估划不划算（個性貪財的比較難談）。
- **擺攤**：在村莊或城市的安全區域按背包的「🏪 擺攤」，點擊物品放上攤位並設定單價、取好攤位名稱後開始擺攤，頭上會出現攤位招牌。附近的冒險者會來逛（價格越接近商店售價越容易賣出），線上玩家也能點擊你查看攤位購買；擺攤中無法移動，收攤後未賣出的物品回到背包。各村莊也有冒險者擺的攤販，會定期換一批商品（裝備可能已經強化過）。
- **商店**：購買清單可以依「價格由低到高」「價格由高到低」或「稀有度」排列（會記住選擇）。稀有度分為普通、精良、高級、稀有，以不同顏色顯示，依稀有度排列時會分組並在組內依價格排列。
- **背包**：80 格，可整理、丟棄、刪除（永久銷毀）。
- **負重**：超過 50% 不會自然回復，80% 移動變慢，滿載無法撿取。
- **倉庫**：各村莊與灰岩城的倉庫管理員都能使用「個人倉庫」與「血盟倉庫」（兩者在各地共通）。血盟倉庫可存放物品與金幣，容量 80 格＋每個血盟等級 10 格，並記錄最近的存取紀錄。冒險者的血盟也有各自的血盟倉庫：成員會把戰利品與金幣存進去、補給時動用金庫，金庫累積到一定金額會用來壯大血盟戰力（攻城傳令官可以看到各血盟的倉庫概況）。
- **魔法**：10 個階級共 51 種魔法（含所有職業低等級就能學的「負重強化」，負重上限 +50%）。魔法圖示依系別（火、冰、雷、風、聖、地、秘、武）使用不同顏色的寶石底與邊框，右上角標示階級。第 1～5 階 35 種（含各職業低等級就能學的範圍攻擊：烈焰環、旋風斬、聖光爆、箭雨），第 6～10 階 15 種高階魔法：烈焰風暴、魔力護盾（傷害一半由魔力承受）、神聖護盾、狂暴（騎士）、鷹眼（弓手）、雷霆風暴、大治癒之光、大地震、死亡之雲、神聖審判、萬箭齊發、時間凍結（凍結周圍敵人）、聖域、天崩地裂、神蹟（完全恢復並短暫無敵）。部分高階魔法有冷卻時間。第 1～4 階魔法書向魔法商人購買；第 5～6 階在城堡御用商人與歐瑞城魔法商人有售；第 7～10 階只能從強大的頭目（鋼鐵巨像、霜冠巨人王、炎皇火龍等）身上取得。魔法視窗依階級分組，並顯示魔攻與魔防。防護術、加速術、祝福鎧甲等持續型魔法可以設定「自動施放」（魔法視窗下方，或在圖示上按右鍵），效果快結束且魔力足夠時會自動重新施放。
- **強化**：一般／祝福強化卷軸，超過安全值可能失敗並讓裝備消失。強化卷軸可以用在身上的裝備，也可以用在背包裡的武器與防具。
- **對話**：冒險者與村民各有個性（熱血、冷靜、幽默、貪財、害羞、嘮叨），會記得自己剛剛在哪裡打了什麼。在篝火旁會依照彼此的等級、血盟與世界上發生的事（攻城結果、新血盟、頭目被打倒）多輪對話：練功心得、強化成敗、血盟邀請（真的會入盟）、攻城討論、討價還價、約好一起出發（真的會一起離開）、談論附近的你；旁人也會插話。野外遇到時會互相提醒紅名。向他們詢問攻城時間、城主、最近的消息、練功地點等，也會依照實際情況回答。
- **冒險者的生活**：野外的冒險者會消耗藥水、撿戰利品，藥水用完或包包滿了就回村莊買補給、存倉庫，在篝火旁休息並互相聊天，再找傳送師回去練功。
- **PK 與善惡值**：野外有其他冒險者與紅名的邪惡冒險者。Ctrl／Shift＋點擊可強制攻擊（紫名 20 秒），被誤打的冒險者 8 秒後就不再追打；殺害無辜者會變成邪惡，村莊守衛會出手警告一次（之後 2 分鐘內不再攻擊），死亡時會掉落物品。
- **血盟**：等級 5 支付 3000 金幣建立，自訂名稱與徽章；在村莊或野外點擊冒險者邀請加入。血盟有 1～10 級，捐獻資金升級可提高成員上限（5＋魅力÷2＋每級 3 人）、狩獵經驗、召集人數與攻城兵力；盟主可設定副盟主／精英、剔除成員、編輯公告、更換徽章；「捐獻紀錄」分頁依金額排列每個人（含盟主）捐獻給血盟的金幣與占比；`/c 訊息` 使用盟頻聊天，成員會上線、升級、捐獻並在盟頻聊天。
- **攻城時間**：固定在現實時間每 2 小時開放一次（0:00、2:00、4:00…），每次 20 分鐘。只有攻城時間內可以向攻城傳令官宣戰，傳令官和畫面上方會顯示下次攻城時間與倒數。
- **攻城**：在灰岩城外向攻城傳令官宣戰，10 分鐘內攻破城門、摧毀守護之塔即可成為城主。電腦血盟正在攻城時，你的血盟也可以加入，誰先摧毀守護之塔，城堡就歸誰。
- **冒險者的血盟**：等級夠高的冒險者會自己創立血盟（最多 6 個）並招募其他冒險者，血盟會隨時間成長。攻城時間開始時，這些血盟和老牌血盟會向灰岩城宣戰，城堡可能被電腦血盟佔領，你要再打回來；你是城主時則要守城（不在場時由守軍防守，但有機會失守）。傳令官會列出大陸上的血盟勢力。
- **城堡駐軍**：灰岩城的城門與守護之塔有常備守衛站崗（攻城戰之外不會攻擊一般人，陣亡後 90 秒補員，頭上顯示目前城主的血盟）。城主可以向傭兵隊長花錢把守衛訓練為精銳守衛／鐵衛軍／皇家近衛（最多 10 名），也能雇用傭兵劍士、弓手、法師、重騎士（最多 8 名，合約 24 小時、可續約或解約）。傭兵可以設定「跟隨」或「駐守」：跟隨的傭兵會跟著你到各地（包含其他地圖）一起戰鬥，駐守的傭兵留在城內和守衛一起對抗攻城的血盟（傭兵隊長、夥伴視窗或 `/merc follow|stay` 切換）。
- **城堡傳送師**：灰岩城內的傳送師可以送你到大陸各地與北境，城主血盟免費。
- **宮廷魔法師**：在灰岩城為勇者施放防護術、祝福鎧甲、大地之膚、力量祝福、神聖武器、加速術、抗火結界（持續 10 分鐘），也有八折的全套祝福；城主血盟免費。
- **城門**：城主可以點擊城門（或向攻城傳令官說話）開關城門，關上後所有人都無法通過；開關狀態會記住，攻城戰結束後也會維持。城門被攻破時要等攻城戰結束才會修好，失去城堡時城門會重新打開。
- **王城**：灰岩城有圓頂宮殿、藍頂塔樓、城牆上的王家旗幟、從城門直通宮殿的紅毯大道、騎士雕像與王家路燈，南北兩座有噴泉的皇家花園。城主的稅金、稅率與復活點由宮殿前的**城堡管家**處理。
- **反覆攻城**：電腦血盟被擊退後，可能在城外重整旗鼓，於同一次攻城時間內再進攻（最多 3 輪，每次人數更多）；攻城戰結束後若攻城時間還有剩，也可能有血盟再發動一次。
- **城主**：稅收來自所有勇者（包含電腦冒險者）打怪掉落的金幣與商店交易，稅率 5～20% 可調；城主頭上有旋轉的王冠。城主血盟專屬：城堡御用商人（雜貨商人的所有商品加上祝福卷軸、王家秘藥、經驗卷軸、各地傳送卷軸、寵物用品等）、城內的「地下要塞」練功副本、血盟倉庫容量 +50（黑暗騎士、石像鬼、火焰小鬼與頭目鋼鐵巨像，掉落王者系列裝備）、城堡御用商人（祝福強化卷軸、王家秘藥）、復活點可設在灰岩城、狩獵經驗 +10%。
- **入盟申請**：其他冒險者（包含別的血盟成員）會主動詢問是否能加入你的血盟；也可以挖角別的血盟成員（成功率較低，血盟等級與擁有城堡會提高）。
- **召喚戒指**：魔法商人、歐瑞城魔法商人、城堡御用商人販售，部分頭目也會掉落。使用後依你的等級選擇召喚的生物（野狼、狼人、雪原狼、地獄犬、雪怪、冰晶巨像、霜巨魔、熔岩巨像、龍人戰士，Lv.44 可召喚赤鱗飛龍），強度隨等級與魔攻成長，與召喚術共用 3 隻上限。
- **夥伴系統**：召喚術（狼靈、岩石巨像、火焰元素，強度隨等級與魔攻成長）、迷魅術（讓怪物暫時成為盟友）與寵物共用跟隨／戰鬥行為，可切換「攻擊我的目標／自由攻擊／待命／跟隨」（T 鍵）。加速術與寵物活力藥劑可以讓夥伴加速。夥伴擊殺的經驗值一半歸主人、一半歸夥伴。
- **寵物**：5 種原創寵物（灰狼、雪狐、刺甲豬、夜梟、戰熊），以及 4 種會施放魔法的寵物：焰狐（火球）、霜牙狼（冰錐並使敵人減速）、雷鷹（落雷，可能連鎖）、光之精靈（聖光攻擊，主人受傷時會治療）。寵物大餐可以補滿寵物體力。向寵物商人購買，或用馴獸肉乾馴服野狼；最多可同時帶 3 隻寵物出戰；寵物會升級、可改名、收進寵物項圈帶著走，倒下後到寵物商人復活。
- **名字**：玩家名字不分大小寫不能重複，也不能使用 NPC、冒險者、怪物的名字；電腦角色之間的名字也不重複。
- **聊天欄**：拖曳下方面板上緣，或按聊天欄右上角的 ▲▼，可以調整聊天欄大小（會記住）。
- **聊天**：附近的冒險者、NPC 與寵物會依關鍵字回應；支援 `/help`、`/who`、`/w`、`/roll`、`/pickup`、`/mode`、`/stuck` 等指令。
- **自動拾取**：走過的物品自動撿起，閒置時會去撿 10 格內的掉落物（設定或 `/pickup` 開關）。自己丟棄的物品不會被自動撿回，需要時可以手動點擊撿起。
- **存檔備份與轉移**：設定中可匯出角色 .json 或複製「存檔碼」，在選擇角色畫面「匯入角色」或「備份全部」。
- **畫面**：昏暗中世紀色調（可在設定中關閉）、日夜循環、地下城的火把光照。
- **音訊**：登入畫面為原創的王室進行曲。遊戲中每個村莊、地區、地下城都有專屬的原創曲（共 23 首，例如晨風村〈晨光小調〉、銀風港〈海風之歌〉、幽影森林〈林間低語〉、熾焰火山〈熔岩之心〉、月影遺跡〈沉睡的月光〉），被頭目盯上或在攻城戰中會切換成戰鬥音樂；曲子由程序作曲引擎依照調式、和弦進行、樂器與節奏型譜成，換區域時會淡入淡出並顯示曲名。另有原創主題曲《晨曦大陸》（降 B 小調、管風琴與法國號的史詩風格），預設在大陸野外播放（可在設定中關閉，改回各區域的曲子）。商店售價比道具原本價值高 50%，強化卷軸為 5 倍；商人收購價依原本價值計算。音效全部程序化生成；音樂與音效可分別開關。

## 多人連線（第一階段）

**推薦：用 Supabase（免費方案即可）**——不需要自己的伺服器，遊戲網頁放在 GitHub Pages，帳號、存檔與即時同步交給 Supabase。完整教學見 **[docs/SUPABASE.md](docs/SUPABASE.md)**：建立專案 → 關閉信箱驗證 → 執行 `supabase/schema.sql` → 把 Project URL 與金鑰填進 `js/config.js`。

以下是另一種做法：自架 Node 伺服器。

目前可以「看得到彼此、共享聊天」：伺服器只負責帳號、角色存檔、聊天，以及同步玩家的位置與外觀；怪物、NPC、戰鬥與掉寶仍由每位玩家的瀏覽器各自計算（所以玩家之間不能互相攻擊或組隊）。

啟動伺服器（需要 Node.js 18 以上）：

```
cd server
npm install
npm start
```

然後用瀏覽器開啟 `http://伺服器位址:8080/`，登入畫面會顯示「線上模式：已連線到伺服器」。可用環境變數 `PORT` 改連接埠、`DATA_DIR` 改存檔資料夾（預設 `server/data/db.json`）。對外開放時建議放在 HTTPS 反向代理後面（WebSocket 路徑為 `/ws`）。

- 遊戲網頁與伺服器分開架設時，可用 `?server=wss://主機/ws` 指定伺服器；`?offline` 強制使用本機模式。找不到伺服器時會自動改用本機模式。
- 線上模式的帳號與角色存在伺服器，和本機模式的資料是分開的；可以在本機模式「匯出角色」，再到線上模式的選擇角色畫面「匯入角色」。
- 聊天：一般聊天傳給附近的玩家，`/all 訊息` 全頻，`/w 名字 訊息` 悄悄話，`/r 訊息` 回覆悄悄話，`/c 訊息` 也會傳給同名血盟的線上玩家，`/who` 列出線上玩家與所在地圖。點擊其他玩家會帶入悄悄話。
- 同一個帳號在別處登入時，原本的連線會被中斷；斷線時會自動重新連線並上傳存檔。

`js/net.js` 把帳號、角色存檔與玩家指令（移動、攻擊、施法、撿取、對話）都包在 `Net` 介面後面，`LocalBackend` 與 `RemoteBackend` 共用同一組介面。下一階段可以讓伺服器接手怪物與戰鬥的計算（`Net.intent(...)` 已經把玩家的行為集中送出），所有實體也都有唯一 id，便於同步。

## 版本與更新

目前版本記錄在 `js/version.js` 的 `GAME_VERSION` 與根目錄的 `version.json`。發佈新版時，執行 `python3 tools/bump_version.py 新版本號 "更新說明"`，會同時更新這兩處與 `index.html` 中的 `?v=` 參數（`?v=` 用來避免瀏覽器使用舊的快取檔案）。

遊戲每 60 秒（以及切回分頁時）會讀取伺服器上的 `version.json`，發現比自己新的版本時會自動存檔，並在畫面上方提醒玩家重新整理。`version.json` 的 `notes` 欄位可以寫這次更新的說明。用 `file://` 直接開啟時不會檢查。
